#### Penjelasan singkat:
**-	Penggunaan Git dan Github:** 
Menggunakan Git untuk mencatat setiap perubahan kode supaya rapi dan tidak hilang, membuat cabang kode baru (branch), dan kode utama aman di branch main. Setelah dibuat branch baru, digabung kode ke branch utama lewat Pull Request, dan memperbaiki kode yang tabrakan (merge conflict). 

**-	Penggunaan npm dan vite:**
Npm adalah alat untuk mengunduh dan mengatur semua bahan atau pustaka (library) yang dibutuhkan aplikasi.
Vite adalah alat untuk menjalankan aplikasi di komputer saat coding (development). Vite juga bertugas sebagai bundler, yaitu mengumpulkan dan membungkus semua file kode yang terpisah-pisah menjadi satu folder dist yang ringkas saat aplikasi sudah selesai dan siap dikumpulkan (build).

**-	Penerapan Typescript:**
Mengunakan Typescript supaya kode lebih aman dan minim error. Typescript juga bertugas sebagai compiler/transpiler, yaitu mengubah kode Typescript yang ditulis menjadi kode JavaScript biasa supaya bisa dibaca dan dijalankan oleh browser internet.

**-	Pengelolaan Environment Variables:**
Menggunakan file .env untuk menyimpan informasi rahasia aplikasi, dan file gitignore untuk memberitahu Git supaya tidak mengunggah file .env ke internet (GitHub), supaya data aplikasi tetap aman dan tidak tersebar.
